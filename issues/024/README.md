### Comment 3: commenter 13, 2008-06-16 00:18 UTC

```
How about something like this:
Ground blood splatter shows up on normal vision and thermals.  It can be cleaned up 
using blankets, paper, extinguisher spray, fire, or 'solvent'.  It can be scanned 
with the 'forensics scanner' which poops out a card with the person's UI dna on it.

If cleaned up with blankets, paper, or extinguisher spray, or let to sit for a 
period of time (say 5 minutes?) the blood is no longer normally visible but there is 
still 'residue' for the thermals to pick up.  This can be scanned the same way as 
normal blood can, provided you can see it.  Fire or 'solvent' completely cleans up 
the blood leaving no residue, or can be used on the residue itself to clean that.  
After another 5 minutes the residue itself would disappear.

(The disappearing parts here are mostly so that if nobody cares about the hallways 
full of smeared blood then it will eventually go away on its own)

'Solvent' would be basically space bleach.  If used on blood or residue the solvent 
would remove it and replace it with a tile of solvent, which could still be scanned 
with the forensics scanner, at least until it dried up (say 30 seconds?)
```
