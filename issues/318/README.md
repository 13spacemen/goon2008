### Comment 0: commenter 25, 2008-12-12 23:04 UTC

```
I don't play anymore, but for you guys, I think it would be neat to have 
whatever is the prison at this point have individual cells (maybe 1,2, or 3 
squares large) that can have their doors set on a timer at which point the 
prisoner can be released back into the station by themselves.

This makes locking people up require an officer to simply put them inside 
the cell, set the lock for a certain time (depending on the crime), and 
then leave. Since even during peak hours for a server there won't usually 
be an officer monitoring the cell(s), this can automate the process a 
little bit. 

What this will require:
-a small remapping of prison cells to have their exit points in an open-to-
the-station area so that prisoners may exit themselves.

-create a door object with a built-in timer that unlocks it after a certain 
time.
```
