### Comment 1: commenter 24, 2009-01-07 00:31 UTC

```
Ogre3D is a very solid, open source, graphics engine with a strong community and
documentation; that said it obviously lacks audio (relatively unimportant) and
networking (relatively critical + difficult)

Irrlicht is an open source graphics engine with an established community and weak
documentation; I've used it before, but come away dissapointed.

Crystal Space 3D is supposedly a decent 3D graphics engine with an emphasis on the
non-graphics things it does well, but appears a poor competitor to Ogre

OpenAL is a solid, open source, audio engine; I've never used it, but have heard good
things

I've yet to use a full-fledged game engine, but a couple available ones include
NeoEngine, modding games such as HL2 (see Eternal Silence), and this whole list at
DevMaster - http://www.devmaster.net/engines/list.php?fid=14&sid=0
```
