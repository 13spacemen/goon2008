The Brig, Security, and the Bridge should all have independent access, so
going to the bridge or brig doesn't involve opening up the security door.

To do this:
Wall off the direct path from the bridge to the outside through security,
and  perhaps make it 2 tiles wide, where it would be going through the old
security.

This separates the brig, bridge access hallway, and security.

For the brig, make an entrance south of the hallway to the bridge, and for
security make an entrance north of the bridge hallway.
