### Comment 5: commenter 24, 2008-07-04 02:13 UTC

```
There are a couple (possibly quick) ways to implement this. I think Capn Lurch's
suggestion of imagining fire extinguishers as basically just a valve which happens to
have high pressure CO2 attached to it is good. That allows us to simplify the code (a
welder is the same, but includes a burner at the end) and expand player options (an
O2 welder, plasma welder, a non-functioning N2O burner, a water spiggot...)
```
