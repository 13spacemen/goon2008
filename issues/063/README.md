```
Very hot, very high pressure fires can and do push things (including mobs) through
firedoors. Airlocks are impervious to fire, though.
```

### Comment 2: commenter 2, 2008-05-25 02:42 UTC

```
I think a solution to this would be adding a "melting point" variable to every item.
Firedoors and Rwalls would have very high melting points, rglass too for engine use.
But make lightweight walls, girders, grills, and regular glass melt at significantly
lower temperatures.

Might take several tweaks to balance correctly and reworking of map items, but if we
can define a blanket default melting point that is the highest normal value it would
be doable at least in the shortterm.
```
